# SCOOTER RENTAL SERVICE DATA ANALYSIS
## Исследование данных о пользователях сервиса аренды самокатов

## Описание проекта
Cервис аренды самокатов GoFast предоставляет пользователям два основных тарифа: без подписки и с подпиской Ultra. Каждый тариф имеет свои особенности стоимости поездок.  Это исследование поможет оптимизировать тарифные планы, а также разработать стратегию удержания и привлечения клиентов.

## Цель проекта
Изучение предпочтений клиентов сервиса и проверка гипотез, которые могут способствовать росту бизнеса. 

## Данные
В рамках данного исследования доступен массив данных о пользователях из нескольких крупных городов, их поездках, а также информация о применяемых тарифах. 

## Этапы проекта
- **Загрузка и предобработка данных:** первичная проверка данных на соответствие типов, обработка пропусков, дубликатов и выбросов при наличии.
- **Исследовательский анализ:** исследование поведения пользователей в зависимости от выбранного тарифа, частоты и длительности поездок, а также других факторов.
- **Проверка гипотез:** исследование гипотез о характерном поведении с точки зрения использования сервиса самокатов  и доходах от группы клиентов с подпиской.
- **Ad hoc задачи:** аналитические расчеты для проведения маркетинговых кампаний по привлечению и удержанию пользователей.
- **Выводы и рекомендации:** резюмирование результатов анализа, формулировка ключевых выводов и рекомендаций по улучшению тарифных планов и стратегии удержания клиентов.

## Результаты
В ходе работы изучены характерные особенности поездок пользователей с подпиской и без. Проверены гипотезы по которым можно сделать вывод о том, что пользователи с подпиской выгоднее для сервиса за счет более длительных поездок и высокой среднемесячной выручки. Необходимо разработать маркетинговую стратегию для привлечения и удержания большего количества пользователей на тарифном плане 'ultra'. Дополнительно рассчитаны необходимые показатели для проведения маркетинговых акций (рассылка промокодов, уведомлений).
